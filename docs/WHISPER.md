# Whisper

Whisper распознает русскую речь и время слов. Признаки мошенничества ищет прежний RuBERT; сам Whisper их не оценивает.

Используем `Systran/faster-whisper-small`, ревизию `536b0662742c02347bc0e980a01041f333bce120`, через faster-whisper 1.2.1. Это готовая конвертация OpenAI Whisper small для CTranslate2, лицензия MIT. Веса не дообучаем. На CPU используется int8. Источник: [карточка модели](https://huggingface.co/Systran/faster-whisper-small/tree/536b0662742c02347bc0e980a01041f333bce120).

## Подготовка

В отдельном окружении проекта установить группу `whisper`, либо всю группу `media`. Общий рабочий venv не синхронизировать. Скачать веса отдельной командой:

```bash
uv run --isolated --locked --group whisper python -m ml.prepare_whisper
```

Получится `var/ml/media/whisper-small`: четыре файла модели и `manifest.json` с ревизией, размерами и SHA-256. Команда использует закрепленную ревизию; повторный запуск позволяет продолжить загрузку. Веса находятся вне Git.

В `ANALYZER_DIR/media.json` указать audio.whisper_dir относительно папки комплекта, фактическую ревизию в model_versions.whisper и quality по [примеру](../examples/media.json). Пока pyannote не готов, убрать diarization_dir и model_versions.diarization. Для настоящего разделения говорящих позже добавить оба поля. После изменения нужен перезапуск процесса.

Для сайта нужны обе группы: `ml` и `whisper`. Одна группа `whisper` позволяет отдельно проверить ASR без PyTorch и pyannote. Группа `media` уже включает `whisper`.

## Работа

- Веб-запрос ничего не скачивает. Загрузчик проверяет локальные файлы, а при наличии подготовленного manifest — их ревизию и хеши.
- Вход остается WAV PCM16, 16000 Гц, до 60 секунд. Whisper получает русский язык, выделение речи VAD и время каждого слова.
- Сомнительные слова сохраняются с ограничением; низкая уверенность не означает отсутствие опасности.
- Без pyannote участники остаются неизвестными, непустой результат имеет статус partial. Тишина дает empty. Неизвестные участники разных реплик не объединяются в одного автора.
- Текст, время и ограничения идут в существующий Analyzer. Правила предупреждений не меняются.

Пороги quality пока стартовые, а не измеренная точность. Успешный прогон двух постановочных записей не доказывает качество на реальных звонках. Разделение голосов, наложения и скорость на VPS проверяются отдельно.
