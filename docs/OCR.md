# Распознавание скриншота

Используем EasyOCR 1.7.2: CRAFT находит строки, cyrillic_g2 читает русский и английский текст. Веса скачиваются отдельно с официальных GitHub Releases и не входят в Git.

## Подготовка

```bash
uv run --isolated --locked python -m ml.prepare_ocr
```

Получится `var/ml/media/easyocr` с craft_mlt_25k.pth, cyrillic_g2.pth и manifest.json. Подготовщик проверяет опубликованный MD5 каждой сети, затем записывает SHA-256 и размер. Повторный запуск использует уже готовые файлы. Источники и хеши закреплены в `analysis/screenshot.py`; это [конфигурация EasyOCR 1.7.2](https://github.com/JaidedAI/EasyOCR/blob/v1.7.2/easyocr/config.py).

Для запуска распознавания нужна группа `media` из uv.lock. В ANALYZER_DIR/media.json добавить блок screenshot по [примеру](../examples/media.json): путь `../media/easyocr` и min_confidence=0.5. Перезапустить процесс после изменения.

## Обработка

1. Сервер проверяет PNG/JPEG и ограничения размера.
2. Загрузчик проверяет наличие обеих сетей и, для подготовленного комплекта, SHA-256 и размер файлов. EasyOCR запускается на CPU с download_enabled=False.
3. OCR возвращает текст, рамки строк и свои оценки. Геометрия объединяет строки внутри пузырей и определяет стороны A/B по расположению.
4. Если обе стороны не различимы, авторы остаются неизвестными. Низкая оценка OCR или неоднозначный порядок дают partial; текст сохраняется с ограничениями.
5. Реплики и рамки идут в прежний RuBERT и правила предупреждений. OCR не оценивает мошенничество и не определяет владельца аккаунта.

Форматы и временные файлы: [MEDIA.md](MEDIA.md). Порог 0.5 стартовый, не измеренная точность. Поддержка произвольного оформления мессенджеров не гарантируется; неподходящая геометрия явно ограничивает вывод.

Локально без сети проверены два постановочных PNG: распознаны три реплики A/B/A, опасный пример дал баннер, обычный — нет. Распознавание заняло примерно 2.0 и 1.2 секунды на этом компьютере. В обычном примере есть мелкие ошибки текста и пунктуации. Это проверка работы цепочки, не оценка точности на реальных переписках и не замер выбранного VPS.
