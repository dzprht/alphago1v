# Разделение голосов

Используется `pyannote/speaker-diarization-community-1`, ревизия `3533c8cf8e369892e6b79ff1bf80f7b0286a54ee`, с pyannote.audio 4.0.7 на CPU. Модель автоматически определяет интервалы говорящих. Метки A/B обозначают разные голоса, а не владельца записи.

## Подготовка

Модель требует принятия условий владельцем аккаунта: [community-1](https://huggingface.co/pyannote/speaker-diarization-community-1). Затем выполнить локальный `hf auth login` и подготовить файлы отдельной командой:

```bash
uv run --isolated --locked --group media python -m ml.prepare_diarization
```

Загружаются пять файлов из одного закрепленного снимка: config, segmentation, embedding и два файла PLDA. Подготовщик сохраняет ревизию, размеры и SHA-256 в manifest.json. Веса и токен не публикуются в Git. Веб-запросы скачиваний не выполняют.

Для уже подготовленного каталога повторное скачивание не нужно: перенести его целиком в `var/ml/media/pyannote`. В `ANALYZER_DIR/media.json` указать audio.diarization_dir=`../media/pyannote` и model_versions.diarization=`pyannote/speaker-diarization-community-1@3533c8cf8e369892e6b79ff1bf80f7b0286a54ee`. После изменения перезапустить приложение.

Локальный каталог передается Pipeline.from_pretrained абсолютным путем. Pyannote 4.0.7 разрешает `$model/...` внутри config относительно этого каталога; YAML и рабочую директорию менять не нужно. Загружаются все зависимые модели с диска, pipeline явно переводится на CPU.

## Связь с Whisper

Whisper дает слова и время. Pyannote дает обычные интервалы голосов, включая наложения. Слово получает участника только при полном и однозначном покрытии. Во время наложения или пробела участник неизвестен. Исключительные интервалы, принудительно назначающие один голос в каждый момент, не используются.

Надежно определенные реплики одного голоса могут накапливать предыдущие текстовые признаки. Неизвестные участники не объединяются. Качество распознавания, неизвестные голоса и пересечения отображаются как ограничения результата.

Без подключенного pyannote Whisper продолжает работать: говорящие неизвестны и ответ partial. Это не подтверждает готовность автоматического разделения. Проверка на настоящем разговоре требует локальных весов и проводится отдельно от тестов с подставными ответами.

Локально проверены готовые веса без сети: одноголосая демозапись и постановочный контроль A/B/A с русским Milena и английским Daniel. Диаризация различила два голоса и вернула первый после второй реплики. Этот смешанный контроль проверяет разделение голосов; успешной проверкой русскоязычного ASR-диалога он не считается. При отсутствии слов для обнаруженного голосового интервала ответ partial с отдельным пояснением.
