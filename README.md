# Альфа Защита

Веб-сервис для проверки текста, ссылок, аудиозаписей, скриншотов переписки и обстоятельств предполагаемого перевода. Русский язык, платежи в рублях, пользователи в РФ.

**На 4 ноября 2026 года подготовлены основа Django, аккаунты, формы, хранение и завершение проверок, CSV, отзывы и отдельное согласие на обучение.** HTTP подключен для аккаунтов, своей истории, результатов, CSV и отзывов; страницы используют общий CSS и шаблон полей. Есть лимит входа. Локально работает PostgreSQL 17.11, проходят 211 тестовых случаев основной реализации; GitHub Actions настроен. Офлайн реализованы текст и URL: для текста механизм проверен на демонстрационном наборе, для URL CatBoost обучен на PhiUSIIL и проверен на validation с отдельными доменами. Независимое качество на свежих данных ещё не измерено. Главная и формы пяти режимов подключены. Формы текста, ссылки и перевода подключены к Analyzer при настроенном комплекте моделей; без него ввод не сохраняется. На этом этапе загрузки аудио и скриншотов были выключены; HTTP подключен 5 ноября, порядок настройки приведен ниже. Подготовлен запуск через Gunicorn; провайдер и публичное размещение пока отсутствуют. Добавлены общий стиль страниц и адаптация для телефона. Разработка с нуля на Django + Django Templates + PostgreSQL.

5 ноября добавлены ручной ввод до 100 операций и объединение совпадающих признаков анкеты с моделью. Результат показывает «Указано вами» и «Обнаружено в сообщении», при двух основаниях — обе подписи. Справочник ожидаемых организаций расширен до 63 записей. Подключены правила предупреждений, Modified Z-score и флаг отсутствия получателя в истории. Проходят 284 основных теста.

## Запуск и проверка

Зависимости зафиксированы в lock-файле; перед запуском после обновления нужно установить их по инструкции ниже. Локальный `.env` создан и исключён из Git. Проверка настроек из корня проекта:

```bash
source /Users/Shared/github/MachineLearning/ml_venv/bin/activate
python manage.py check
```

Установка зависимостей по lock-файлу без очистки общего venv:

```bash
uv export --locked --no-dev --no-emit-project --format requirements-txt --output-file /tmp/alphago1v-requirements.txt
uv pip install --python "$VIRTUAL_ENV/bin/python" -r /tmp/alphago1v-requirements.txt --require-hashes
```

Перед этими командами нужно активировать venv как показано выше. На другой машине также нужен `.env` по примеру `.env.example` с собственными секретами.

PostgreSQL запускается через `compose.yaml`. На текущем компьютере выполнены запуск БД и применение миграций. После установки Docker команды из корня проекта:

```bash
docker compose up -d --wait db
python manage.py migrate --noinput
python -m pytest -q
```

Если Docker ещё не добавлен в PATH, на macOS команды находятся внутри `/Applications/Docker.app/Contents/Resources/bin/`, а Compose — в `Resources/cli-plugins/docker-compose`.

Тестовые зависимости входят в группу `dev`. Для установки вместе с ними в приведенной команде `uv export` убираем `--no-dev`. После запуска PostgreSQL тесты выполняются командой `python -m pytest -q`. GitHub Actions запускает их на PostgreSQL 17 при push и pull request, предварительно проверяя настройки и миграции.

Для локальной проверки аккаунтов после запуска БД и миграций:

```bash
python manage.py collectstatic --noinput
python manage.py runserver
```

Откройте `http://127.0.0.1:8000/accounts/register/` или `/accounts/login/`. После входа `/accounts/` ведет на `/checks/` и `/transactions/`. Можно открыть свою сохраненную проверку, оставить отзыв, изменить отдельное согласие, скачать шаблон, импортировать или удалить свою историю операций. Главная `/` ведет на `/checks/new/<kind>/`. При настроенном ANALYZER_DIR формы выполняют анализ: аккаунт получает сохраненную проверку, гость — временный ответ. Для аудио и скриншотов дополнительно нужен media.json с локальными весами. Без готового комплекта возвращается 503 без сохранения; неверный файл отклоняется до распознавания. Пять неверных попыток входа с одного IP за 15 минут включают отказ 429. Это локальный сервер разработки, не команда публичного размещения.

## Текстовая модель

Общий вход — `analysis.features.Turn`: текст, ID реплики, необязательный говорящий и место в исходном материале. `analysis.text.TextModel` обучает семь классификаторов поверх замороженного E5. На выходе — текущие и предыдущие оценки с источниками; итоговые предупреждения собирают правила, HTTP использует общий Analyzer при готовом комплекте.

Технический запуск на [14 демонстрационных примерах](examples/text_train.jsonl):

```bash
uv run --isolated --locked --group ml --no-dev python -m ml.train_text examples/text_train.jsonl var/ml/text-demo --download
```

Группа `ml` добавляет PyTorch и Transformers. Изолированное окружение использует lock-файл и сохраняет общий venv других проектов. `--download` явно разрешает первое скачивание закреплённого E5; затем используется кэш `var/ml/cache`. Результат сохраняется в новую папку: существующая не перезаписывается. Веса и обучающие артефакты исключены из Git.

JSONL содержит `case_id`, `group_id`, `split`, `turns`, `target_turn_id`, `fragment_id`, семь `labels` и семь `evidence` в порядке `TEXT_LABELS`. Метки — 0/1/null; положительная цитата должна находиться в целевом фрагменте. Для собственной независимой validation используется `--validation путь.jsonl` со `split=validation`, без общих групп и случаев с train. `test` и `calibration` не принимаются как обучающий файл.

Демонстрационная разметка синтетическая и не проверена независимо; её прогнозы не являются готовым анализом мошенничества. Источники рабочего корпуса, разбиение и дальнейшее обучение: [ML_PLAN.md](ML_PLAN.md). Обычный CI запускает тесты без скачивания E5; реальный ML-прогон проверяется отдельно.

## URL-модель

Справочник ожидаемых организаций расширен до 63 записей и 165 доменов. Названия предлагаются в форме проверки ссылки. Источники, ограничения и обновление уже сохраненных моделей: [BRAND_CATALOGUE.md](docs/BRAND_CATALOGUE.md).

`analysis.url.URLModel`: 12 признаков строки → CatBoost; отдельно проверяется соответствие бренда подтверждённым доменам. Проверяемые сайты не открываются. На выходе — оценки, маски доступности и адреса-источники для правил предупреждения. HTTP использует этот блок через общий Analyzer при настроенном комплекте.

Подготовка [PhiUSIIL, UCI](https://archive.ics.uci.edu/dataset/967/phiusiil+phishing+url+dataset), CC BY 4.0, и обучение:

```bash
python -m ml.prepare_urls var/ml/urls/new-data --download
python -m ml.train_url var/ml/urls/new-data/train.jsonl var/ml/url-new --validation var/ml/urls/new-data/validation.jsonl --source-manifest var/ml/urls/new-data/source_manifest.json
```

Команды используют активированный venv с основными зависимостями, без группы `ml`. ZIP скачивается только по явному флагу; его SHA-256 проверяется. Используются только исходный URL и метка, без готовых HTML-признаков. Дубли удаляются, зарегистрированные домены не пересекаются между частями. Выходные папки должны быть новыми; данные и артефакты находятся вне Git в `var/`.

Текущий артефакт: `var/ml/url-01`. Train — 172086 адресов, validation — 19662; F1 0.992975 при диагностическом пороге 0.5. Это результат данного корпуса, не оценка свежих реальных ссылок. Calibration и test не оценивались. Параметры, остальные метрики и ограничения — в [ML_PLAN.md](ML_PLAN.md).

## Признаки перевода

`analysis.transfer.transfer_features` считает 10 числовых признаков суммы и исходящей истории; неизвестные значения остаются None для общего сборщика масок. Отдельная модель здесь не обучается. Форма перевода принимает пять вопросов с фиксированными ответами и unknown по умолчанию, без свободного пересказа; оригинальную просьбу можно добавить отдельно. H/N передаются правилам предупреждений; дерево для новых проверок не используется.

## Предупреждения и общий запуск

Новые проверки используют явные правила, без итогового дерева и классов риска. Баннер: `C or P or R or F or (M and (U or S or A)) or (D and (H or N))`. H+N без смены реквизитов остаются замечаниями. Полная таблица, неизвестные значения и источники: [WARNING_POLICY.md](docs/WARNING_POLICY.md).

`Analyzer.prepare` собирает признаки; `analyze` применяет правила. `run_check` передает только свою историю аккаунта, сохраняет результат и производные показатели без полного CSV. У гостя история не используется. HTTP-медиа подключены через временные файлы и отдельно настроенные локальные распознаватели; после обработки или ошибки файлы удаляются. Старые сохраненные результаты открываются без пересчета.

`ANALYZER_DIR` содержит text/, url/ и calibration.json с восемью порогами и версиями двух моделей. Дерево не требуется. Текущие адаптеры — E5+LR и CatBoost; выбранные rubert-tiny2/CNN нужно подключить отдельно. Загрузчик использует локальные веса и не скачивает модели из HTTP. Без комплекта POST дает 503 без создания проверки. Подготовка запуска: [DEPLOYMENT.md](docs/DEPLOYMENT.md).

## Подготовка обучения и медиа

`analysis/audio.py`: Whisper + pyannote → слова, говорящие и реплики. `analysis/screenshot.py`: EasyOCR → рамки, пузыри и стороны. HTTP вызывает эти локальные адаптеры через load_media_model; реальные ASR/OCR-веса в текущем окружении еще не запускались. Геометрия пузырей пока прототип, поддержка оформления всех мессенджеров не подтверждена.

`ml.prepare_risk` строит групповые OOF-признаки и итоговые нижние модели; `ml.train_risk` обучает дерево; `ml.score_cases` получает независимые оценки; `ml.calibrate` сохраняет восемь порогов. Рабочий корпус еще предстоит подготовить, обучение не запускалось. Форматы и порядок команд — [docs/ML_WORKFLOW.md](docs/ML_WORKFLOW.md). ## Интерфейс

Страницы используют `templates/base.html`, общий вывод полей `templates/includes/form_fields.html` и `static/css/site.css`. Небольшой `static/js/transactions.js` добавляет строки ручного ввода без перезагрузки; без JavaScript работает серверная кнопка. Кнопки, ошибки, результаты, история, CSV и аккаунты оформлены одинаково; таблица имеет отдельную прокрутку на телефоне. WhiteNoise отдает собранные CSS и JS при DEBUG=False; порядок сборки — в [DEPLOYMENT.md](docs/DEPLOYMENT.md). Формы аудио и скриншотов принимают файлы; доступность распознавания зависит от локальных весов и media.json.

## Загрузка медиа — 5 ноября

Аудио: WAV PCM16, 16000 Гц, один или два канала, до 60 секунд и 4 МиБ. Скриншот: статический PNG/JPEG, до 5 МиБ и 4 млн пикселей. Проверяется содержимое, не только расширение.
