**Пользовательские сценарии**

Все проверки доступны без входа. У гостя ответ остается только на текущей странице, у вошедшего пользователя сохраняется в истории. Ошибка обработки не считается безопасным результатом.

**S01. Аккаунт и история — F01, F08**

1. Зарегистрироваться и войти.
2. Сделать любую проверку и открыть ее в истории.
3. Выйти, затем войти с теми же данными на другом устройстве.
4. Открыть прежний результат. Он должен сохраниться без повторного анализа.

Неверный пароль не дает войти. Чужую историю открыть нельзя.

**S02. Текст — F02**

1. Открыть проверку текста и вставить сообщение. Контекст можно добавить по желанию.
2. Нажать «Проверить».
3. Посмотреть найденные признаки, исходные фрагменты и рекомендации.

Пустой текст не принимается. Пример для проверки: «Срочно переведите деньги на безопасный счет. Никому не говорите».

**S03. Ссылка — F03**

1. Вставить URL. При желании добавить сообщение, ожидаемую организацию и контекст.
2. Запустить проверку и прочитать результат.
3. Если указан известный банк, посмотреть его официальный контакт в рекомендациях.

Некорректный адрес не принимается. Сервис не открывает проверяемый сайт.

**S04. QR-код — F04**

1. Загрузить PNG/JPEG с одним QR-кодом. При желании добавить сообщение, организацию и контекст.
2. Запустить проверку.
3. Посмотреть извлеченную ссылку и результат ее анализа.

Несколько кодов, нечитаемый QR или содержимое не в виде HTTP(S)-ссылки дают ошибку. Для показа есть `examples/demo/qr-warning.png`.

**S05. Скриншот — F05**

1. Загрузить скриншот личной переписки в PNG/JPEG. Контекст необязателен.
2. Запустить проверку.
3. Посмотреть распознанную переписку и найденные признаки.

Текст и стороны переписки определяются автоматически. Если распознать изображение не получилось, сервис сообщает об этом. Пример — `examples/demo/warning.png`.

**S06. История операций и перевод — F06, F07**

1. После входа загрузить CSV по шаблону из README или ввести операции строками. По умолчанию они добавятся к истории, с галочкой «Заменить всю историю» — заменят ее.
2. Открыть проверку перевода. История необязательна, гость сразу начинает с этого шага.
3. Указать сумму в рублях и назначение. При желании добавить получателя, текст просьбы и ответы анкеты.
4. Посмотреть результат: признаки из текста, ответы анкеты и доступные сведения из своей истории.

Неверная строка импорта не меняет прежнюю историю. Без истории перевод тоже проверяется. Сервис не проводит платежи.

**S07. Отзыв и согласие — F08, F09**

1. Войти и открыть свою завершенную проверку из истории.
2. Указать исход: мошенничество, обычная ситуация или неизвестно. Можно добавить комментарий.
3. При желании отдельно разрешить использование этой проверки для будущего обучения. Отзыв можно оставить без разрешения.
4. Сохранить. Позже отзыв можно исправить, а согласие — отозвать.

Прежний прогноз не меняется. Отзыв не запускает обучение и не считается проверенной разметкой. Для гостевой, чужой или неудавшейся проверки отзыв недоступен.
