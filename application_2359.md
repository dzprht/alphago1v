## Целевая аудитория / заказчик (человек или группа, которым нужен ваш продукт)

Проект ориентирован на пользователей онлайн-платежей, которым требуется помощь
в оценке подозрительных обращений: подростков и молодых пользователей с небольшим
опытом самостоятельных платежей; пожилых пользователей с ограниченным опытом цифровых
сервисов; взрослых, редко совершающих онлайн-переводы. Возраст сам по себе не считается
признаком низкой грамотности: в исследовании будет учитываться фактический опыт
участников. Формального внешнего заказчика нет.

## Проблемное поле

По сообщению не всегда понятно, действительно ли человеку пишет знакомый, сотрудник организации
или мошенник. Просьба перевести деньги может выглядеть правдоподобно, а подозрительная ссылка
— почти не отличаться от привычного адреса. При этом пользователя могут торопить, не оставляя
времени разобраться.

Я хочу сделать сервис, в котором можно проверить такую ситуацию до перевода денег или передачи
личных сведений. Пользователь получит объяснение, какие признаки требуют внимания и что стоит
проверить самостоятельно.

## Образ продукта

«Альфа Защита» — веб-сервис для проверки сообщений, ссылок и обстоятельств предполагаемого
перевода. Для работы достаточно открыть сайт в браузере.

Пользователь сможет:

- зарегистрироваться и войти в свой аккаунт;
- ввести текст сообщения или ссылку для проверки;
- описать обстоятельства, при которых его просят перевести деньги;
- загрузить историю транзакций в CSV-файле по предложенному шаблону;
- получить результат с выявленными признаками риска, пояснениями и рекомендациями;
- открыть историю своих проверок и вернуться к сохранённому результату.

История транзакций будет учитываться при оценке предполагаемого перевода. Пользоваться
сервисом можно будет и без неё, но в таком случае результат будет основан только на введённых
сведениях о ситуации.

Сервис не подключается к банковскому счёту, не выполняет и не блокирует переводы. Отсутствие
найденных признаков риска не будет означать гарантию безопасности

## Ресурсы, необходимые для реализации проекта

Для разработки нужны компьютер, доступ в интернет, среда разработки и GitHub для хранения
исходного кода. Также понадобятся документация используемых инструментов и примеры сообщений,
ссылок и транзакций для проверки работы сервиса. Для демонстрации можно использовать

Для размещения приложения нужен хостинг, на котором можно запустить серверную часть и хранить
базу данных. Для проверки удобства работы потребуется обратная связь от пользователей.

## Чему мне придётся научиться в процессе выполнения проекта?

Мне нужно научиться доводить веб-приложение до состояния, в котором другой человек может
пользоваться им без моей помощи. Для этого придётся разобраться с регистрацией и входом,
хранением данных, обработкой загружаемых файлов и размещением приложения на сервере.

Отдельная задача — научиться проверять качество анализа и понятно объяснять его результат. Нужно
учитывать случаи, когда сервис ошибается, пользователь вводит некорректные данные или сведений
недостаточно для вывода.

## Возможные риски и пути их преодоления

- Получать ошибочные результаты анализа. Проверять сервис на обычных, подозрительных и
неоднозначных примерах, разбирать ложные срабатывания и показывать ограничения результата.
- Получить некорректный CSV-файл. Предоставить шаблон и пример заполнения. При загрузке
проверять данные и понятно объяснять, что нужно исправить.
- Не получить достаточно сведений для оценки. Сообщать об ограничениях и недостающих данных
вместо необоснованного вывода.
- Столкнуться с проблемами запуска. Заранее проверить приложение на хостинге и при локальной
установке, подготовить пошаговую инструкцию.
- Сделать непонятный интерфейс. Собрать обратную связь от пользователей и доработать места, где
им потребовалась помощь.

## Итоговый продукт

Результатом проекта станет работающий сайт «Альфа Защита». На нём можно будет проверить
сообщение, ссылку или описанную ситуацию перед переводом денег, прочитать объяснение
результата и вернуться к сохранённой проверке в личном аккаунте.

Пользователь сможет загрузить историю своих транзакций в CSV-файле по шаблону сервиса. Эти
сведения будут использоваться при оценке предполагаемого перевода.

Вместе с сайтом будут представлены исходный код на GitHub, инструкция для локального запуска,
шаблон CSV-файла и примеры для демонстрации. По этим материалам другой человек сможет
запустить приложение и проверить его основные функции.
