**[ НАЗВАНИЕ ПРОЕКТА ]**

«Альфа Защита» — веб-сервис проверки подозрительных обращений и обстоятельств перевода.

**[ ПРОБЛЕМНОЕ ПОЛЕ ]**

По сообщению не всегда понятно, действительно ли человеку пишет знакомый, сотрудник организации или мошенник. Просьба перевести деньги может выглядеть правдоподобно, а подозрительная ссылка — почти не отличаться от привычного адреса. При этом собеседник может торопить пользователя, пугать последствиями или требовать сохранить разговор в тайне.

Сервис показывает подозрительные признаки и помогает перепроверить просьбу до перевода денег или передачи личных сведений. Здесь лучше лишний раз предупредить, чем пропустить опасную просьбу.

**[ ЗАКАЗЧИК / ПОТЕНЦИАЛЬНАЯ АУДИТОРИЯ ]**

Русскоязычные пользователи онлайн-платежей в РФ, совершающие переводы в рублях:

- подростки и молодые пользователи с небольшим опытом самостоятельных платежей;
- пожилые пользователи с ограниченным опытом цифровых сервисов;

**[ ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ ]**

1. **F01. Аккаунт.** Регистрация, вход, выход и доступ к своим данным с другого устройства.
2. **F02. Проверка текста.** Анализ сообщения на признаки подозрительных просьб с объяснением результата.
3. **F03. Проверка ссылки.** Анализ URL и сопоставление с указанной ожидаемой организацией, если она распознана.
4. **F04. Проверка QR-кода.** Извлечение одной HTTP(S)-ссылки из изображения, показ адреса и его анализ.
5. **F05. Проверка скриншота.** Извлечение текста переписки из PNG/JPEG и анализ ее содержания.
6. **F06. Проверка перевода.** Учет анкеты, текста просьбы и доступной личной истории: нетипичной суммы и отсутствующего в истории получателя. Без истории проверка тоже доступна.
7. **F07. Импорт истории.** Загрузка CSV или ручной ввод строками. Предусмотрено как полное обновление истории, так и ее частичное дополнение.
8. **F08. История проверок.** Просмотр своих сохраненных результатов.
9. **F09. Обратная связь.** Добавление исхода и отзыва. При соответствующем согласии со стороны пользователя эти данные будут использованы в дальнейшем для дообучения моделей.

Наше основное отличие — проверка предполагаемого перевода с учетом личной истории операций. Сервис отмечает нетипичную сумму и получателя, которого нет в загруженной истории, и учитывает эти признаки вместе с текстом просьбы и ответами анкеты.

**[ ИНСТРУМЕНТЫ РАЗРАБОТКИ, ИНФОРМАЦИЯ О БД ]**

- **Сервер:** Python и Django — аккаунты, формы и обработка запросов.
- **Интерфейс:** Django Templates, HTML, CSS и JavaScript.
- **База данных:** PostgreSQL — пользователи, операции, результаты проверок, отзывы и согласия. Связи между таблицами и транзакции нужны для согласованного сохранения и замены истории.
- **Анализ:** PyTorch, Transformers, rubert-tiny2 для семи текстовых признаков, символьная CNN для URL. Итог — явные правила, анкета и статистика операций.
- **Изображения:** EasyOCR для текста переписки, OpenCV для QR-кодов.
- **Среда разработки:** macOS, терминал, Python 3.11, uv, Git и GitHub.
- **Проверки и запуск:** pytest, pytest-django, GitHub Actions, Docker Compose, Gunicorn и Nginx.
